# Alexander Vizhnay — Portafolio

Portafolio personal de Alex, desarrollador de Cuenca, Ecuador. Presenta su historia, proyectos, experiencia en sistemas y formas de contacto.

## Ver el sitio

El proyecto es estático y no requiere instalación ni compilación. Para abrirlo localmente, sirve esta carpeta con cualquier servidor estático y visita `http://localhost:8080`.

## Publicación con GitHub Pages

Este repositorio se llama `erickvzh`, así que la dirección del sitio será:

`https://alekspaucar.github.io/erickvzh/`

En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda los cambios y espera a que termine la publicación. GitHub Pages servirá el `index.html` de la raíz, que abre el sitio ubicado en `dist/`.

Para actualizar el portafolio, sube los cambios de esta carpeta a la rama `main`; Pages volverá a publicar el sitio.

## Editar el contenido

- `dist/index.html`: presentación, perfil y contacto.
- `dist/projects.js`: proyectos, descripciones y galerías.
- `dist/style.css`: diseño y adaptación a pantallas.
- `dist/app.js`, `dist/weather.js`, `dist/avatar.js`, `dist/hands.js` y `dist/skills.js`: navegación, animaciones e interacciones.
- `dist/assets/`: capturas y recursos visuales del sitio.

El contacto abre correo, WhatsApp, Instagram y GitHub. Las animaciones respetan la preferencia de movimiento reducido del dispositivo. No hay formularios que guarden datos ni mensajes enviados automáticamente.
